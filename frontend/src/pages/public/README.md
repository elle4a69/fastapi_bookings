# Public Surface: Single-Page Website & Umbrella Directory (`frontend/src/pages/public`)

The public pages module implements the customer-facing acquisition, branding, and booking discovery surfaces for **FastAPI Bookings**.

---

## 1. Purpose & Scope

The public module owns:
1. **Public Single-Page Website** (`/site` or `/site/:subdomain`): A responsive, branded website generated by the business owner via the Website Builder.
2. **Embedded Booking Engine**: Directly embedded within `/site` or `/book`, allowing visitors to book appointments without navigating away.
3. **Umbrella Marketplace & Geo-Radius Directory** (`/directory`): Marketplace directory with map discovery, distance calculation from visitor postcode/suburb, and instant clinic booking links.
4. **Proactive Chat & Greeting Widgets**: Floating visitor greeting banners with quick intent chips.

This module deliberately avoids exposing backend administrative endpoints, internal calendar notes, or private customer records to unauthenticated visitors.

## 3. Setup, Configuration & Dependencies

### Runtime Dependencies
- **React & TypeScript**: Client-side rendering and responsive layout primitives.
- **Lucide Icons**: Clean visual icons for navigation, location pins, telephone triggers, and ratings.
- **Mapbox GL / OpenStreetMap**: Geospatial map rendering and pin clustering.
- **Backend Endpoints**: Queries public unauthenticated endpoints `/api/public/website/{subdomain}`, `/api/public/directory/search`, and `/api/public/travel/addresses`.

### Environment Variables
- Optional: `VITE_MAPBOX_TOKEN` for enhanced vector tile styling in directory maps.

## 4. Core Workflows & Contracts

### 4.1 Website Builder & Live Rendering
- **Templates**: Modern Minimalist, Wellness & Sanctuary, Clinical & Medical, Luxury & Boutique.
- **Themes**: Ocean Slate, Emerald Oasis, Rose Gold, Royal Indigo, Monochrome.
- **Embedded Booking Modes**: Native FastAPI Booking Form or headless Cal.com embed.
  - **Checkout Estimation**: Dynamically computes out-call travel requirements, rendering transit time and travel fee quotes inline. Fully integrates with dynamic pricing models (Per-KM, Fixed, Tiered, and Uber Pass-Through).
- **Proactive Chat Invitation**: Floating invitation banner that prompts visitors with friendly greetings and quick booking chips.

### 4.2 Geo-Radius Directory & Search
- Queries `/api/public/directory/search` with `lat`, `lng`, and `radius_km`.
- Computes geodesic distances using Haversine algorithm (`DistanceCalculator`).
- Renders clinic cards with rating, starting price, and 1-tap "Book Online" links.

---

## 5. Data Safety & Isolation

- **Unauthenticated Public Scoping**: Public endpoints strictly isolate data to public fields (`name`, `bio`, `public_services`, `location_city`); internal notes, financial records, and staff schedules are completely omitted from responses.
- **Discreet Address Protection**: For clinics marking `is_client_hidden: true`, physical street addresses are replaced with suburb/city level approximations in directory listings and website cards.
- **Rate Limiting**: Public search and booking endpoints enforce SlowAPI rate limits to prevent automated crawling or denial-of-service bursts.

---

## 6. Known Issues, Edge Cases & Outstanding Work

- **Browser Geolocation Fallback**: When visitors decline browser location prompts, the directory falls back to postcode/suburb text input.
- **Custom Subdomain DNS Propagation**: Custom custom domain resolution (CNAME mapping) requires wildcard reverse proxy routing.
- **SEO Pre-Rendering**: Dynamic single-page client rendering benefits from server-side metadata tagging for social media OpenGraph cards.
